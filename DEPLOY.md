# Deploy: Render + Neon

Backend (Docker) and admin (static site) run on Render via `render.yaml`; PostgreSQL runs on Neon.

## 1. Neon
The project already exists: `jemis` (id `royal-brook-04650407`, region `aws-eu-central-1`, Postgres 16, branch `main`,
database `jemis`, role `jemis`). Direct host: `ep-square-breeze-batpr53y.c-8.eu-central-1.aws.neon.tech`, so
`JEMIS_DB_URL=jdbc:postgresql://ep-square-breeze-batpr53y.c-8.eu-central-1.aws.neon.tech/jemis?sslmode=require`.
The role password is only in the Neon console (Connect → role `jemis`); do not commit it.

Generic steps, if you need to recreate it:
1. Create a project (region close to Render's `frankfurt`, e.g. `aws-eu-central-1`).
2. Copy the **direct** connection details (host without `-pooler`). Flyway takes advisory locks, which break behind the
   transaction pooler.
3. Build the values:
   - `JEMIS_DB_URL=jdbc:postgresql://<host>/<db>?sslmode=require`
   - `JEMIS_DB_USER` / `JEMIS_DB_PASSWORD` from the Neon role.
4. Optional: a Neon branch per PR lets you run migrations against a copy of the data before merging.
   Scale-to-zero adds a few seconds on the first request after idle; the Hikari timeout in `render.yaml` allows for that.

## 2. Render
1. New → Blueprint → select this repository. Render reads `render.yaml`.
2. Fill the prompted secrets: `JEMIS_DB_URL`, `JEMIS_DB_USER`, `JEMIS_DB_PASSWORD`,
   `JEMIS_BOOTSTRAP_ADMIN_EMAIL`, `JEMIS_BOOTSTRAP_ADMIN_PASSWORD` (the first admin is created only if none exists).
   `JEMIS_JWT_SECRET` is generated by Render.
3. If the backend URL is not `https://jemis-backend.onrender.com`, update the `/api/*` rewrite destination in `render.yaml`.
4. Verify: `GET https://<backend>/actuator/health/readiness` returns `UP`, then log in to the admin site.

## Notes
- Real payment provider, SMS/push and maps are not configured (see README); the mock payment provider stays off in production.
- Rate limiting is in-memory per instance; keep one backend instance or move it to a shared store before scaling out.
- The mobile app should use `--dart-define=API_BASE_URL=https://<backend>` and its origin may need `JEMIS_CORS_ORIGINS` only if it is a web build.
